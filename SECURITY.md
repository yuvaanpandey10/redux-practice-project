# Security Policy

## Supported Versions

This project is currently in active development. Please use the latest version on the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue. Instead, contact the maintainer privately and include:

- a clear description of the issue
- affected files or components
- reproduction steps if available
- suggested remediation, if known

We will review and respond as quickly as possible.
