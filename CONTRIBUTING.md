# Contributing

Thanks for your interest in contributing to this project.

## Development setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Code style

- Keep code readable and consistent with the current structure.
- Prefer small, focused components and Redux slices.
- Validate with the project build before submitting changes.

## Pull requests

- Create a feature branch from `main`.
- Keep pull requests focused on a single issue or feature.
- Include a brief summary of the changes and any screenshots if UI is affected.
